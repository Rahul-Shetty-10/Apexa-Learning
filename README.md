# HRB Apexa Learning

Next.js App Router conversion of the original website.

Run `npm install` then `npm run dev`. For production, run `npm run build` then `npm start`.

- `app/page.jsx`: original page converted to JSX
- `app/globals.css`: original styles
- `app/layout.jsx`: document and metadata
- `public/site.js`: original graph, menu, form and motion interactions
- `public/assests/`: original images

`apexa.html` is retained as the original reference.
